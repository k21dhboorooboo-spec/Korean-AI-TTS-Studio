# KOREAN AI TTS STUDIO v0.9 — 개선 버전

## 실제 제공 범위
- 기존 v0.8 기능(한/영/일 MeloTTS 연결, SRT 타임라인, 음성 라이브러리, 캐시, 일괄 처리, OpenVoice V2 연결)을 계승합니다.
- **대사 감정 자동 추천** 체크박스 추가: 키워드 기반 보수적 규칙이며 AI 문맥 감정 분석이 아닙니다. `{분노}` 등 명시 태그가 항상 우선합니다.
- SRT 작업 시작 인자 전달 오류 수정(기존 v0.8에서 감정 이름이 batch 매개변수에 잘못 전달됨).
- 일괄 처리 성공 판정을 출력 파일 존재 및 크기로 확인합니다.
- 언어 접두사 `[EN:John]`의 음성 선택 및 캐시 키 계산 개선.

## 설치/실행
Windows 64비트 Python 3.10, Git 설치 후 `install_windows.bat`, `start_windows.bat`를 실행하세요. MeloTTS와 일본어 사전 설치는 네트워크 및 Windows 호환성 영향을 받습니다. 모델 최초 다운로드 후 로컬 합성이 가능합니다. OpenVoice V2는 별도 모델 및 체크포인트가 필요합니다. `build_windows.bat`는 빌드 스크립트이지 미리 빌드된 EXE가 아닙니다.

## 한계 및 미검증
- 감정: 속도/음량 근사만 제공. 진짜 감정 발화, 속삭임, 울음, 연기 제어 **미구현**.
- 음성 복제: 허가받은 샘플만 사용. Windows CPU 통합 검증 **미완료**.
- 이 실행 환경에서 실제 Windows 설치형 EXE 빌드 및 MeloTTS 음성 출력은 수행할 수 없습니다.
- SRT 속도 보정은 피치를 변경할 수 있으며, 구간 초과 시 경고하고 기본적으로 대사를 자르지 않습니다.

## 검증
`python -m unittest discover -s tests -v` (소스 폴더에서 실행).
