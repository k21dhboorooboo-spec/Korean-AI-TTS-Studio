# v1.0 신경망 감정 엔진 (실험적)

기존 v0.9의 속도·음량 기반 가짜 감정 대신 **Chatterbox Multilingual** 신경망 음성 합성을 연결하는 별도 GUI `neural_app.py`를 추가했습니다. 모델의 exaggeration 매개변수로 감정 표현 강도를 조절합니다. 이는 기쁨/분노 등의 감정을 직접 제어하는 전용 감정 토큰이 아니므로, 선택한 감정이 정확하게 표현된다고 보장할 수 없습니다. 감정 이름은 강도 프리셋이며 연기 유형은 대본과 참조 음성에 의존합니다.

## Windows CPU 설치
Python 3.11 64-bit 설치 후 `install_neural_windows.bat`, `start_neural_windows.bat` 순서로 실행. 처음에는 모델 다운로드에 인터넷 필요. CPU 속도와 메모리 요구량이 높을 수 있음. 설치 실패 시 패키지 버전 호환성 확인 필요.

## 기능과 제한
- 한국어/영어/일본어 언어 선택, 신경망 표현 강도, 허가받은 참조 음성 WAV/MP3 선택, SRT 시간 시작 동기화 및 경고 리포트.
- SRT에서 화자별 언어 태그와 감정 태그 지원. **화자별 서로 다른 참조 음성 자동 매핑은 아직 없음**: 현재 선택한 참조 음성 하나를 전체 대사에 적용함.
- SRT 대사 초과 시 원음 보존 우선: 지정 종료 시각을 넘으면 경고. 출력 WAV는 24kHz PCM을 목표로 변환.
- 모델의 실제 지원 매개변수와 Windows 설치는 아직 실기 검증되지 않음. PyInstaller 설치형 EXE 미제작.
- 음성 복제는 본인 음성 또는 명시적 허가를 받은 음성만 사용.
- 설치 스크립트는 온라인 패키지 설치이며 완전 오프라인 설치 패키지가 아님.

## 검증
신경망 모델을 다운로드하지 않은 환경에서 구문 검사와 순수 로직 단위 테스트만 수행. 실제 합성/음질/Windows 설치 테스트는 미실시.
