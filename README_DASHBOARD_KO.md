# KOREAN AI TTS STUDIO v1.4 대시보드

## 추가된 기능
- 언어/감정/참조음성 설정을 위쪽에 배치한 직관적 3단 구성
- 대본 분석: TXT/SRT 구간 수, 화자 수 표시
- SRT 구간별 완료 수, 진행률 막대, 경과 시간, 완료 구간 기반 예상 남은 시간
- 생성 완료/오류 상태 및 저장 경로 표시, 오류 팝업
- 작업 중 종료 확인

## 진행률의 의미
진행률은 **완료된 음성 구간 수 / 전체 구간 수**입니다. 모델 로딩과 현재 구간의 내부 추론 진척도는 알 수 없습니다. 첫 구간에서 0%로 오래 머무를 수 있습니다. 예상 남은 시간은 첫 구간 완료 이후 계산되며 실제 소요 시간과 다를 수 있습니다. 100%는 최종 WAV 믹싱과 저장이 완료된 뒤에만 표시됩니다.

## Windows 업데이트
