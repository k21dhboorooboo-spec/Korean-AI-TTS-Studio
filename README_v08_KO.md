# v0.8 감정 선택 확장

기존 v0.7의 다국어, 음성 라이브러리, SRT, 일괄 처리, 캐시 및 설치 빌드 스크립트를 유지합니다.

- 감정: 기본/기쁨/슬픔/분노/놀람/공포/속삭임/진지함/다정함/긴박함
- 감정 강도: 0~1. SRT 개별 대사는 `[며느리] {분노} 그만하세요!` 형식으로 지정.
- 현재 감정 표현은 **속도 및 음량 조정 기반 근사치**이며, 신경망 감정 연기/실제 속삭임·울음·떨림을 구현한 것은 아닙니다.
- 한국어/영어/일본어 모델과 OpenVoice 설치는 기존 README_KO.md 참고.
- Windows EXE는 `build_windows.bat`로 Windows 환경에서 별도 빌드해야 합니다. 여기서 EXE 실행 검증은 하지 않았습니다.
- SRT 감정 태그는 음성으로 읽히지 않도록 제거합니다.
- 캐시 키에 감정 및 강도를 포함해 서로 다른 설정의 음성이 섞이지 않게 했습니다.
